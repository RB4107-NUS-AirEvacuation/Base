# CAD model and fabrication pack (Rev C2)

Mechanical design of the robot, modelled in Fusion 360. Rev C2 (3 Nov 2026) is the version that
was built: acrylic plates, PETG brackets, steel shafts and bought pulleys and belts.

| Folder | Contents |
|---|---|
| `step/` | STEP model of every part, plus `RB4107 full assembly Rev C1 (robot + track + levelling + chair).step` |
| `drawings/` | Detailed assembly drawing (16 sheets), part detail drawings, acrylic drawings, change sheet, 3D-print request |
| `laser-cut-dxf/` | DXF files for the laser-cut acrylic plates (P1, P2, P9, P12, P13, P16, P28) and drilling templates |
| `3d-print/` | STL (and STEP) files for the PETG brackets, the levelling brackets (L1–L5) and the TPU test track |
| `parts-list/` | Bill of materials, fastener and connector list, and build checklists (Excel) |
| `README - Rev C (fabrication pack notes).txt` | Change log and fabrication notes for Rev C1 → C2 |

Part numbers (P1 to P28) match the drawings and the report. Dimensions are in millimetres.

The MuJoCo model in `../simulation/model/` was exported from the same CAD.
